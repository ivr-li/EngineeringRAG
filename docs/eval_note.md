# Оценка качества

## Назначение

Eval-контур нужен для регрессионной проверки во время разработки retrieval и
answer-generation пайплайна. Он помогает сравнивать конфигурации и отслеживать,
улучшают или ухудшают изменения поиск evidence.

## Набор данных

Текущий набор содержит 200 доменных вопросов по строительной тематике. Каждый
пример включает ожидаемое направление ответа и source evidence: документ,
раздел или таблицу.

Набор данных поддерживается внутри проекта. Его нельзя предоставить как benchmark.

## Текущие метрики

| Метрика | Значение |
|---------|----------|
| Вопросов | 200 |
| `de_recall@5` | 0.85 |
| `de_recall@10` | 0.92 |
| `ee_recall` | 0.85 |
| `ce_recall` | 0.83 |
| `MRR` | 0.69 |
| `faithfulness` | 0.93 |
| `answer_relevance` | 0.95 |

## Значение метрик

- `de_recall` - ожидаемое evidence найдено в прямой выдаче retrieval.
- `ee_recall` - ожидаемое evidence найдено после expansion по ссылкам и таблицам.
- `ce_recall` - ожидаемое evidence попало в финальный LLM-контекст.
- `MRR` - позиция первого релевантного evidence.
- `faithfulness` - LLM-as-judge оценка подтвержденности ответа контекстом.
- `answer_relevance` - LLM-as-judge оценка соответствия ответа вопросу.
